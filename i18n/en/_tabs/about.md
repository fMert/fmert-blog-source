## Furkan Mert Bağcı (fMert)

I'm Furkan Mert Bağcı, and I share my work online as **fMert**. I live in Türkiye and study engineering at Aksaray University. I'm interested in Linux, open source software, AI-assisted development, terminal tools, Android development, and software that solves practical problems.

I describe my current work as a mix of **prompt engineering**, **software development**, and **open source experiments**. I enjoy building tools for writing, note-taking, local AI, developer workflows, and communication systems.

## What I'm building

### Queyntisen

An AI-focused terminal Markdown editor written in Python.

Queyntisen began as a simple terminal editor. I later developed it into a lightweight, terminal-first alternative to Obsidian. It supports Markdown editing, preview and source modes, fluid writing workflows, and a built-in AI assistant.

### Aria

A desktop AI companion and chat application centered on memory, mood, diary-like state tracking, and persistent character behavior.

Aria is an experiment in local AI interaction, personality continuity, and desktop application design.

You can find the source code for my projects and other open source work on [my GitHub profile](https://github.com/fMert).
